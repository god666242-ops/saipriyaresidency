# sri-sai-residency
Budget hotel website (Vijayawada). Next.js 14, no CSS framework.
- npm install && npm run dev  (http://localhost:3101)
- Edit site.js only: name, address, phone, WhatsApp, rooms, prices, nearby places, slug (PureBook hotel slug), embed colour/label, url.
- Photos: the hotel's own photos are in public/images and mapped in images.js (referenced from site.js).
- Deploy: push to Vercel, set site.js url to the live domain.
